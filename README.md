# PDF-Functions
Allows for merging and encrypting PDF documents. More updates to come.

Trying to combine two PDF documents for free online is a hassle. You need to pay, make an account, or do both just to do this simple function. Through this repository, you can merge two pdf documents and even encrypt the documents. I plan on updating this repository with a GUI and more PDF functions. 

This project was created to help me solve a problem I was facing in my life (merging two documents without having to create an account or pay for a feature) and help me understand how Python works with documents and the read/write functions.
